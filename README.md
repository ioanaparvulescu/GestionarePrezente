# GestionarePrezente

University Attendance Management System.

## Description

A web application designed to manage student attendance
at university courses and seminars.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

### Backend
- Python
- FastAPI
- Pydantic

### Database
- Microsoft SQL Server
- Raw SQL

## Features

- User authentication
- Student management
- Group management
- Course management
- Attendance tracking
- Attendance statistics
- Reports
